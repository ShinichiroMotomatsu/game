# game

## ROPPONGI CHRONICLES

六本木から芝公園までの同じ地形を、二つの時代から探索する見下ろし型RPGプロトタイプです。

## 物語の時代

- `現代編-昼間`: 現在の六本木。アスファルト道路と現代の5ランドマーク／6建物パーツ
- `過去編-夕方`: 中世ヨーロッパ風の剣と魔法の王国。石畳、王城、魔導学院、魔導宮殿、王宮庭園、魔導塔、大聖堂

`index.html` で編を選択でき、探索画面内でも位置を保ったまま切り替えられます。

## 過去編の序章と戦闘

- 西の港から王都へ到着し、王の依頼を受けて西の港街道と古い見張り台を調査
- 王都には武器屋、防具屋、道具屋、宿屋、カード屋があり、装備・道具・デッキを更新可能
- 支度金300Gで推奨装備の「銅の剣＋皮の鎧＋やくそう2個」を購入可能
- 街道を巡回する4体のシンボル敵に接触するとカード戦闘へ移行
- 初期デッキは「斬撃・火花・防御・集中」の4種類。宝箱での発見やカード屋での購入により、攻撃・回復・補助カードが増加
- 行動力はLv1の1点から始まり、Lv2で2点、Lv4で3点へ成長。行動力を使い切ると選んだカードを自動発動
- 魔法カードはMPを消費し、「集中」でMPを回復可能。「癒光」などの回復魔法もデッキに組み込める
- 敵の予兆は通常非公開。「眼（集中）」を使った次ターンのみ、行動と有効な対抗系統を開示
- 開示された猛攻・結界・大詠唱・再生を適切な系統で看破すると行動を妨害
- 戦闘経験値でレベルが上がり、最大HP・最大MP・攻撃・守備・行動力が成長。装備補正と残HP・残MPは次の戦闘にも継続
- 街道の4体から封印片を集めると、古い見張り台の中ボス「紫霧の番人」に挑戦可能
- 中ボスまでの推奨到達レベルはLv3。初見の会話・買い物・探索込みで約30分を想定
- やくそうと「まほうの雫」は「もちもの」から戦闘外で使用でき、宿屋は12GでHP・MPが全回復
- 敗北時は王都へ戻り、所持金が半分になってHP・MPが全回復
- 敵との接触時は渦巻き暗転を挟んで戦闘画面へ移行
- 過去編画面の「戦闘テスト」から接触なしでも動作確認可能
- 勝利した街道敵は5分後に再出現し、同じ敵からも経験値とゴールドを稼げる（封印片は初回のみ）
- ミッドタウンと麻布台ヒルズ相当の建物は魔力の霧で隠れ、イベントAPIで順番に解放（物語上の真相はプレイヤー向け表示に出さない）

イベント実装時は `window.V2_GAME_EVENTS.completeMemoryEvent(eventId)` を利用します。

- `midtown-memory-restored`: ミッドタウン相当を解放
- `azabudai-memory-restored`: ミッドタウン解放後のみ麻布台ヒルズ相当を解放

## 共通地理

OpenStreetMapのway geometryを同一縮尺・北上で投影し、六本木通り・外苑東通り・国道1号線（桜田通り）・麻布通り（高輪麻布線）・桜麻通り・東京タワー通り・都道301号線（祝田通り）を描画します。二つの編は道路座標、交差点、ランドマークのアンカーを共有します。現代の道路名ラベルは現代編だけに表示し、過去編では非表示です。

道路マスクは中心線と道路幅から生成し、実行時は `road-collision-data.js` の行区間データを使用します。過去編ではさらに海岸線でクリップした専用道路マスクを使用します。ランドマークの当たり判定と輪郭データは削除済みで、移動制限は道路マスクだけです。`M` キーで道路範囲を表示できます。

OSMスナップショットは `assets/v2/osm-road-source.json` です。道路データは © OpenStreetMap contributors、ODbL 1.0です。

## 主な生成処理

- `tools/build-v2-osm-layout.py`: OSM道路をゲーム座標へ投影
- `tools/build-v2-past-assets.py`: 生成した過去編背景、6ランドマーク、4方向主人公をゲーム用素材へ加工
- `tools/build-v2-enemies.py`: 敵素材シートから透過済みの敵3種を生成
- `tools/build-v2-geographic-map.py`: 現代・過去の連続マップ、共通道路判定、ランタイムデータを生成
- `tools/build-v2-day-tiles.ps1`: 連続マップから継ぎ目のない高解像度4タイルを生成（`-Edition past-evening` に対応）

## 操作

- `WASD` / 矢印キー: 移動
- `E` / `Enter`: 話す、調べる、店に入る
- `M`: 道路当たり判定の表示切替
- 過去編ステータスの「もちもの」: 装備確認、やくそう使用
- 画面上部のボタン: 現代編と過去編を切替
- 過去編の「戦闘テスト」: カード戦闘を即時開始

背景画像とランドマーク画像は生成AIで制作したオリジナルのゲーム用アートです。
